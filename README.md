# งานส่งอาจารย์: ระบบจัดการร้านค้า (Store Management System)
**การเขียนโปรแกรมจัดการฐานข้อมูลด้วย Go และ GORM (MySQL)**

---

### 📋 รายละเอียดโปรเจกต์
โปรแกรม Console Application สำหรับจัดการข้อมูลร้านจำหน่ายอุปกรณ์ไอที ประกอบด้วย 4 ตารางหลัก โดยใช้ `gorm.Model` (มี `id`, `created_at`, `updated_at`, `deleted_at`) และกำหนดความสัมพันธ์ Foreign Key ดังนี้:
- **Category (1 : N) Product** (หนึ่งประเภทมีสินค้าได้หลายรายการ)
- **Customer (1 : N) Order** (หนึ่งลูกค้ามีประวัติการสั่งซื้อได้หลายครั้ง)
- **Product (1 : N) Order** (สินค้าเชื่อมโยงกับคำสั่งซื้อ โดยหนึ่ง Order มีสินค้าหนึ่งรายการ)

---

### 📁 โครงสร้างไฟล์
```text
store-management/
├── go.mod          # โมดูลและ dependencies
├── go.sum          # checksum
├── main.go         # เชื่อมต่อ DB, AutoMigrate และทดสอบรันคำสั่ง
├── models.go       # Struct โมเดลทั้ง 4 ตาราง (Category, Product, Customer, Order)
├── category.go     # ฟังก์ชันจัดการ Category (สร้าง, ลบแบบเช็คสินค้าคงเหลือ)
├── product.go      # ฟังก์ชันจัดการ Product (ค้นหาตามราคา/สต็อก/ชื่อ, อัปเดต, Soft/Hard Delete)
├── customer.go     # ฟังก์ชันจัดการ Customer (สร้าง, ค้นหาตาม Email, อัปเดต, ลบ)
└── order.go        # ฟังก์ชันจัดการ Order (สร้าง, ดูประวัติตามลูกค้า/สถานะ/ช่วงเวลา, JOIN รายละเอียด)
```

---

### ⚙️ วิธีการติดตั้งและรันงาน

1. **เตรียมฐานข้อมูล:**
   - เปิด MySQL (XAMPP) แล้วสร้างฐานข้อมูล:
     ```sql
     CREATE DATABASE store_db CHARACTER SET utf8mb4;
     ```

2. **การตั้งค่าใน [main.go](main.go):**
   - ตรวจสอบ `user`, `password`, `host`, `port` ให้ตรงกับเครื่องที่รัน (ค่าเริ่มต้น `root`, ไม่มีรหัสผ่าน, พอร์ต `3306`)

3. **คำสั่งรันโปรแกรม:**
   ```powershell
   go run .
   ```
   *(ใช้ `go run .` เพื่อรันทุกไฟล์ใน package main พร้อมกัน)*

### 🛠 ฟังก์ชันหลักที่พัฒนาตามโจทย์
- **Auto Migration:** สร้างตารางและสร้าง Foreign Key Constraints ใน MySQL อัตโนมัติ
- **Category:** เพิ่มประเภทสินค้า และระบบตรวจสอบก่อนลบ (ห้ามลบหากยังมีสินค้าในประเภทนั้น)
- **Product:**
  - ค้นหาสินค้าตามช่วงราคา (`Price BETWEEN`)
  - ค้นหาสินค้าที่สต็อกเหลือน้อยกว่ากำหนด (`Quantity < Stock`)
  - ค้นหาด้วยชื่อแบบ Partial Match (`LIKE %name%`)
  - ค้นหาแบบหลายเงื่อนไข (หมวดหมู่ + ช่วงราคา)
  - จัดเรียงตามราคา และหาสินค้าราคาสูงสุด N อันดับแรก
  - ระบบ Soft Delete, Hard Delete (`Unscoped`) และการกู้คืนสินค้า (Restore)
- **Customer:** ค้นหาลูกค้าด้วยอีเมล และตรวจสอบประวัติคำสั่งซื้อก่อนอนุญาตให้ลบ
- **Order:** บันทึกคำสั่งซื้อ, ค้นหาตามลูกค้า/สถานะ/ช่วงวันที่ และดึงข้อมูลคำสั่งซื้อพร้อมรายละเอียด (JOIN ตารางลูกค้าและสินค้า)
